계산기연구소 개인정보처리방침

계산기연구소(이하 "본 앱")는 개인정보보호법 등 관련 법령에 따라 이용자의 개인정보를 보호하며, 개인정보를 적절히 처리하기 위한 방침을 수립·시행하고 있습니다.

본 앱은 회원가입·로그인 없이 사용하는 계산기 앱으로, 개인정보 수집을 최소화하는 것을 기본 원칙으로 합니다. 특히 계산기에 입력한 숫자(연봉·시급·금액 등)는 어떤 경우에도 서버로 전송하지 않습니다.

1. 개인정보의 처리 목적

  1. 계산기 요청·문의 접수와 답변 — 이용자가 보낸 요청·문의를 저장하고, 앱 안에서 답변을 보여 주기 위해 익명 세션 식별자를 사용합니다.
  2. 서비스 개선 (익명 사용 통계) — 어떤 계산기가 많이 쓰이는지 파악하기 위해 개인을 식별할 수 없는 사용 이벤트를 수집합니다. 입력값은 포함되지 않습니다.
  3. 광고 서비스 제공 — 앱 내 배너 광고 표시를 위해 Google AdMob이 광고 ID를 수집할 수 있습니다.

2. 수집하는 개인정보의 항목 및 수집 방법

2.1 수집하는 항목

필수 수집 항목: 없음 (회원가입·로그인 기능 없음)

앱이 자동으로 만드는 항목:

  • 익명 세션 식별자: 앱이 처음 실행될 때 무작위로 만들어지는 값입니다. 이름·이메일·전화번호 등 실제 신원과 연결되지 않으며, 요청·문의와 사용 통계에 함께 저장됩니다.

이용자가 직접 보내는 항목 (요청·문의·값 신고 시에만):

  • 요청·문의 본문
  • "이 값이 이상해요"로 값을 신고할 때: 계산기 이름, 화면에 보인 결과와 계산 내역, 적용된 기준 데이터의 기준일
  • 진단 정보: 앱 버전, 운영체제 종류, 운영체제 버전

익명 사용 통계:

  • 이벤트 종류(계산기 열기·공유·달력 열기·근무 기록 저장·요청 보내기·첫 실행 질문 답·달력 이동), 계산기 이름, 발생 시각
  • 사용 통계에는 입력한 숫자가 저장될 자리 자체가 없습니다.

선택 수집 항목:

  • 광고 ID: 광고 서비스 제공을 위해 Google AdMob에서 자동 수집

로컬 저장 데이터 (서버 전송 없음):

  • 계산기에 마지막으로 입력한 값
  • 즐겨찾기·최근 사용 계산기, 홈 고정·숨김 설정, 첫 실행 질문의 답
  • 알바달력의 근무지 설정과 근무 기록

위 로컬 저장 데이터는 이용자의 기기 안에만 저장되며 본 앱의 서버로 전송되지 않습니다. 계산기 입력값은 앱 내 설정 > 입력 기록 지우기로 직접 삭제할 수 있고, 모든 로컬 데이터는 앱 삭제 시 함께 삭제됩니다.

2.2 수집 방법

  • 앱 사용 시 자동으로 수집되는 정보 (익명 세션 식별자, 익명 사용 통계, 광고 ID)
  • 이용자가 앱 안에서 직접 보내는 정보 (요청·문의·값 신고)
  • 이용자가 앱 안에서 직접 만드는 정보 (입력값·즐겨찾기·근무 기록 — 기기 내 로컬 저장만)

3. 개인정보의 처리 및 보유 기간

  1. 요청·문의·값 신고: 답변 및 서비스 개선 목적 달성 시까지 보유
  2. 익명 사용 통계: 서비스 개선 목적 달성 시까지 보유 (실제 신원과 연결되지 않아 특정인을 가려낼 수 없습니다)
  3. 광고 ID: 광고 서비스 제공 기간 동안 보유 (Google 정책에 따름)
  4. 로컬 저장 데이터: 앱 삭제 시까지 보유 (앱 내에서 이용자가 직접 삭제 가능)

원칙: 수집한 정보는 목적 달성 후 지체 없이 파기합니다.

4. 개인정보의 제3자 제공

본 앱은 원칙적으로 이용자의 개인정보를 외부에 제공하지 않습니다. 다만 다음의 경우는 예외로 합니다.

  1. Google AdMob (광고 서비스)
    • 제공 목적: 앱 내 배너 광고 표시
    • 제공 항목: 광고 ID
    • 보유·이용 기간: 광고 서비스 제공 기간
    • Google 개인정보처리방침: https://policies.google.com/privacy

6. 공유 기능 이용 시 유의사항

본 앱의 공유 기능은 "○○ 계산해보기 · 계산기연구소"라는 문장과 앱 설치 링크만 전달합니다. 계산 결과와 입력값은 공유 문장에 포함되지 않습니다. 공유 대상은 전적으로 이용자의 선택에 따르며, 외부 앱으로 전달된 순간부터는 해당 서비스의 개인정보처리방침이 적용됩니다.

7. 정보주체의 권리·의무 및 행사 방법

이용자는 다음의 권리를 행사할 수 있습니다.

  1. 개인정보 열람 요구
  2. 개인정보 정정·삭제 요구: 보낸 요청·문의의 삭제는 이메일로 요청할 수 있습니다. 앱 내 입력값은 설정 > 입력 기록 지우기로 직접 삭제할 수 있습니다.
  3. 개인정보 처리정지 요구
  4. 맞춤 광고 거부: 기기 설정(Google 설정 > 광고)에서 광고 ID 재설정 또는 맞춤 광고를 제한할 수 있습니다.

권리 행사 방법: 이메일(개인정보 보호책임자) 또는 앱 내 설정 > 문의하기

8. 개인정보의 파기

보유기간의 경과, 처리목적 달성 등으로 정보가 불필요하게 되었을 때에는 지체 없이 파기합니다.

  • 전자적 파일 형태: 기록을 복구·재생할 수 없도록 영구 삭제
  • 로컬 저장 데이터: 앱 삭제 시 자동 삭제
